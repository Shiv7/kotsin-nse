# # comments are ignored. STATE is one of:
#   closed   - no session at all
#   evening  - the morning session closed; trading 17:00 to the close (most NSE holidays)
#   morning  - 09:00 to 17:00; the evening session closed
# Every weekday not listed trades both sessions; weekends never trade (a weekend entry is a no-op).
#

# MCX follows the NSE list as before 2026-10-19 and the boot says so. A malformed line leaves MCX on the
# NSE list (boot note "holidays_mcx.txt unreadable"). Never guess a day.
#
